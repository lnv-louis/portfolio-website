# CLAUDE.md — portfolio-website

## Overview

Personal site for Louis Le (lenguyenvu.com): a homepage plus /about, /contact and
/privacy, prerendered to static HTML and deployed on Cloudflare Workers (static assets
+ a small Worker). Light-mode editorial design with red
(#ef4444) accent. Positioning: AI and Real Estate (cf0.ai, Zero). Geist Serif
for H1/H2, Geist for body and H3+, Geist Mono for labels. StyleX design system
modeled on cf0.ai.

## Tech Stack

- **Build**: Vite 8 + `@vitejs/plugin-react`, React 19, TypeScript 5
- **Routing**: no router. `src/app/routes.tsx` maps paths to page components plus their head metadata; each is prerendered to `dist/<page>.html` and hydrated by `src/main.tsx`. Unknown paths get the prerendered `404.html` with a real 404 status.
- **Styling**: StyleX 0.19 via `@stylexjs/unplugin` (Vite). No Tailwind. All styles in `.stylex.ts` files or `stylex.create` calls.
- **Fonts**: Geist + Geist Mono from Google Fonts (`<link>` in `index.html`). Geist Serif Regular self-hosted at `public/fonts/GeistSerif-Regular.woff2` (`@font-face` in `globals.css`, preloaded in `index.html`). The `geist` npm package only ships `next/font` loaders, so it is not used.
- **Motion**: `motion` + `motion-plus` (hero stagger reveal via `splitText`), `lenis` smooth scroll. `MotionConfig reducedMotion="user"` app-wide.
- **UI primitives**: `@base-ui/react` (tooltip)
- **Icons**: `@hugeicons/react` + `@hugeicons/core-free-icons` (direct file imports, not barrel)
- **Dev tooling**: Agentation (visual feedback toolbar), dev-only; the import is gated on `import.meta.env.DEV` so it never reaches the production build
- **Package manager**: Bun 1.4.0 (pinned in `packageManager`), isolated linker (`bunfig.toml`)
- **Deployment**: Cloudflare Workers via Wrangler (`wrangler.jsonc`, account LNV). `src/worker.ts` runs only for page routes (`run_worker_first`) to serve markdown on `Accept: text/markdown` or `?mode=agent` and add `Vary`/`Link` headers; everything else is plain static assets.
- **Agents**: `public/llms.txt` (+ `llms.md`), markdown twins `public/{index,about,contact,privacy}.md`, JSON-LD graph in `index.html`, WebMCP read-only tools in `src/app/agent-tools.ts`, `AGENTS.md` at the repo root.

## Architecture Decisions

- **Prerendered pages**: every route renders to static HTML at build time and hydrates on the client, so crawlers and agents get content without JavaScript. `not_found_handling: 404-page` returns the prerendered 404 with a real 404 status. Adding a page: add it to `routes.tsx`, write `public/<page>.md`, add it to `sitemap.xml`, `llms.txt` and the Worker's `MARKDOWN_TWINS` + `run_worker_first` list.
- **Cascade layers**: `index.html` declares `@layer base, priority1…priority7` first thing in `<head>`; without it, StyleX's dev-injected sheet orders its layers ahead of `base` and the reset overrides components in dev.
- **Hackathon media**: never hand-copy photos. Edit `src/content/hackathon-curation.json` (source path, descriptive `name`, alt text) and run `bun run import-media`. Films go to R2 with `--upload-films` (Range support for Safari), posters to `public/hackathons/`.
- **Rail layout**: 1400px max-width, 1px hairline borders left/right, sections divided by 1px top borders. Modeled on cf0.ai's page shell. No navbar.
- **Stagger reveal**: Hero hides until `document.fonts.ready` (capped at 1s), then splits the headline into lines. Fails open. `prefers-reduced-motion` skips animation.
- **Product film**: Served from the portfolio's own R2 bucket `portfolio` (LNV account, custom domain `media.lenguyenvu.com`) at stable keys `cf0-product-film-720.av1.mp4` and `cf0-product-film-720.h264.mp4` (720×406, ~130 kbps video + 128 kbps AAC audio muxed back from cf0's original encode, faststart, ~1.5 MB each). Not in `public/`: Workers static assets ignore `Range` requests (always 200 full body), and Safari/iOS will not play MP4 without 206 range responses; the R2 custom domain returns 206. Never point at `media.cf0.ai/film/*.<hash>.mp4`: those are cf0's immutable, content-hashed build outputs, so every re-encode or bucket move breaks them. To refresh after cf0 recuts the film, take the current 720p URLs from the cf0.ai homepage `<source>` tags, download them, check `ffprobe` for an audio stream (cf0's re-encodes have dropped it before; mux it from the previous encode if so), and re-upload over the same keys: `CLOUDFLARE_ACCOUNT_ID=062a91f6e4ad306625307277f1fe668b cf r2 objects put <key> --bucket-name portfolio --file <path> --content-type video/mp4`. Update the `codecs` strings if they changed. Poster: `public/zero-product-film-poster.webp`.
- **Hover**: All `:hover` styles are gated behind `@media (hover: hover) and (pointer: fine)` inside the StyleX value so taps don't stick on touch devices.
- **Path alias**: `@/*` resolves to `./src/*` (tsconfig + vite.config.ts + StyleX unplugin aliases).

## Design System

- **Primary**: `#ef4444` (portfolio-brand-700), used scarcely
- **Canvas**: `#f5f5f5` (portfolio-canvas)
- **Surface**: `#ffffff` (portfolio-surface-card)
- **Ink**: `rgba(24, 24, 27, 0.96)` (portfolio-ink)
- **Hairline**: `#e4e4e7` (portfolio-hairline)
- **Fonts**: Geist Serif (H1/H2, weight 400 only — the only weight shipped so far), Geist (body, H3+), Geist Mono (labels). `font-synthesis: none`, so a missing weight never gets faked.
- **Radius**: 0px actions, 6px inputs/buttons, 8px cards, 12px surfaces, pill for CTAs
- **Spacing**: 12-step scale (4px to 192px)
- **Tokens**: Always use `color.*`, `space.*`, `text.*` from `@/tokens/token-consts.stylex.ts`. Never hardcode hex values.

## StyleX Authoring Rules

- **No hardcoded values in components**: Use tokens. New tokens go in `design-tokens.css` + `token-consts.stylex.ts`.
- **No Tailwind**, **no inline `style={{}}`** (exception: SVG filter definitions).
- **Longhand properties**: Split shorthands (`borderWidth` / `borderStyle` / `borderColor`, `paddingBlock` / `paddingInline`).
- **Conditions as values**: `{ default: ..., '@media (min-width: ...)' : ..., ':hover': ... }`. `default` required when any condition exists.
- **Hover**: `':hover': { default: null, '@media (hover: hover) and (pointer: fine)': value }`.
- **Numbers are px**: `width: 24` means 24px. Other units as strings.

## Critical Rules

- **Never hardcode colors** in components — always use StyleX tokens
- **Never use `vh` units** — use `dvh`
- **Always use `--portfolio-*` namespace** for CSS custom properties
- **CSP lives in `public/_headers`**. New media origins must be added to `img-src` / `media-src` there.
